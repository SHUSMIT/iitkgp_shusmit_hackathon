# 5-minute demo script

1. Start Streamlit and click **Use included sample**.
2. Point to the table: one row becomes structured sentiment + event + confidence + impact.
3. Sort by impact and select a high-impact event.
4. Explain that impact >= 7 triggers the stress test.
5. Point to the portfolio before/after values and the asset-level loss chart.
6. Fetch live public data using the **Fetch live news** button to demonstrate ingestion from GDELT + Google News.
7. Explain that FinBERT and MiniLM are optional frozen inference models. The severity score is a transparent heuristic, not a learned market forecast.
