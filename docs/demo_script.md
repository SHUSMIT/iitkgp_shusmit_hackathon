# Module B demo script

1. Start FastAPI and the React/Vite dashboard using the commands in the root README.
2. Select the bundled sample news and run the analysis.
3. Point to the signal table: each article becomes sentiment, event class, confidence, impact score, and stress-trigger status.
4. Open a headline to show the source article, publisher, timestamp, event, sentiment, impact, and confidence.
5. Select the triggered event scenario and show the portfolio before value, stressed value, total loss, event shocks, and asset-level loss chart.
6. Open a loan, bond, derivative, equity, or credit position to show beta, duration, spread duration, PD/LGD-driven credit loss, current P&L, and related news.
7. Fetch live public data once to demonstrate the two-source ingestion path: Google News RSS and GDELT DOC 2.0.
8. State that the included portfolio and sample news are the generated verification data for Module B and that a replacement portfolio CSV can be uploaded.
